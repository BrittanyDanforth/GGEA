NOTE: Dropper 6 (Model Dropper) uses a different system

The Model Dropper (Dropper 6) uses ReplicatedStorage:WaitForChild("CinnamonRoll")
and drops entire models instead of single parts with meshes.

This dropper is fundamentally different from the others and would require
a separate DropperCore.RunModel() function to modernize properly.

The current implementation should continue to work as-is since it:
- Uses PhysicsService collision groups correctly
- Has proper welding
- Includes fade effects
- Uses the same PartStorage system

If you want to modernize this one too, you'll need to create a model-based
version of the DropperCore module.
